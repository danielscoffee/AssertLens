# Sandbox and Modular Architecture Implementation Plan

> **REQUIRED SUB-SKILL:** Use the executing-plans skill to implement this plan task-by-task.

**Goal:** Sandbox local and pull-request checks with Bubblewrap by default while migrating AssertLens into feature-first hexagonal modules.

**Architecture:** `src/assertlens.ts` remains the composition root. Application code depends on Git, check-runner, process, and Jev ports; concrete Node process, Git CLI, direct execution, Bubblewrap, and HTTP adapters implement those boundaries. Sandboxed checks run in disposable Git-visible workspaces and fail closed.

**Tech Stack:** Node.js 24.12+, TypeScript 7, native `node:test`, Git CLI, Bubblewrap, GitHub Actions, TypeSafe Jev HTTP API.

export type ProcessRequest = {
  command: string;
  args: string[];
  cwd: string;
  env?: NodeJS.ProcessEnv;
  timeout: number;
  output: "capture" | "inherit";
  maxBuffer?: number;
  killSignal?: NodeJS.Signals;
};

export type ProcessResult = {
  status: number | null;
  signal: NodeJS.Signals | null;
  stdout: Buffer;
  stderr: Buffer;
  error?: Error;
  timedOut: boolean;
